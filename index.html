Logo Guidelines

Logo Specifications

  • Clear Space: Equal to height of "H" in "Hay2B"
  • Minimum Size (Digital): 120px wide
  • Minimum Size (Print): 1 inch (25mm) wide

Logo Variations

  • Full Logo (Horizontal) - with tagline
  • Logo Mark Only - simplified version
  • Monochrome Version - black & white

✓ DO

  • ✓ Use approved logo files
  • ✓ Maintain color accuracy
  • ✓ Keep proper clear space
  • ✓ Scale proportionally

✗ DON'T

  • ✗ Stretch or distort
  • ✗ Change colors
  • ✗ Add effects
  • ✗ Rotate or modify

Visual Style

Photography Style

  • Subject Matter: Trucks, warehouses, delivery scenes, professional staff
  • Quality: Clean, well-lit, high resolution, sharp focus
  • Composition: Professional, authentic, dynamic
  • Lighting: Natural lighting preferred
  • People: Diverse representation, professional appearance

Graphic Elements

  • Arrows: Yellow/gold, forward-pointing, suggesting progress
  • Icons: Simple, line-based, consistent stroke weight
  • Patterns: Minimal use, subtle diagonals suggesting movement

Layout Principles

  • Consistent grid system for alignment
  • Generous white space
  • Clear information hierarchy
  • Minimum margins: 0.5 inch (12mm)
  • Balance between text and visuals
